# 飞行棋 · 同设备双人

九个版本的纯前端双人飞行棋。两个人在同一台手机、iPad 或电脑上轮流掷骰，支持回合交接遮罩、本地存档和事件自定义。

## 文件

| 文件 | 对应什么 | 说明 |
|------|----------|------|
| `index.html` | 开始页 | 选版本、模式、玩家名，开始新局或继续进度 |
| `game.html` | 正式游戏页 | 同设备轮流掷骰、移动、事件卡、回合交接和本地保存 |
| `settings.html` | 设置页 | 模式、隐私遮罩、玩家颜色、规则开关、自定义事件 |
| `game-data.mjs` | 版本数据 | 九个版本的棋盘和事件文本 |
| `game-engine.mjs` | 规则引擎 | 掷骰、移动、后退、跳转、接受方、胜负 |
| `storage.mjs` | 存档模块 | v2 存档、旧键迁移、自定义事件 |
| `game-ui.mjs` | 游戏 UI | 棋盘、控制区、事件卡和隐私遮罩 |
| `settings-ui.mjs` | 设置 UI | 设置表单和事件编辑 |
| `styles.css` | 共享样式 | 手机、iPad、电脑响应式布局和模式主题 |
| `flight-chess-popup.html` | 兼容入口 | 自动转到 `game.html` |
| `float-window.js` | 浮窗模块 | 游戏页右下角的可拖动状态胶囊 |

## 规则

1. 只有棋子最终停留的格子才触发内容，路过不触发。
2. “后进 X 格”会实际后退；“退回到 N 格”会跳转到指定格。
3. 女仆版 / SM 版无论谁停都由玩家一接受；男仆版无论谁停都由玩家二接受；其他版本由停留者接受。
4. “互相 / 一起 / 双方”按原文作为共同事件展示，不拆成两次惩罚。
5. 两位玩家都在游戏页点击「掷骰」，当前回合由界面显示决定。

## 隐私

- 回合交接遮罩可以在设置中开启或关闭。
- 遮罩只显示交接提示，不显示上一回合的事件文本。
- 所有数据只保存在当前浏览器的 `localStorage`，不上传服务器。

## 自定义

设置页支持玩家名称、棋子颜色、回合交接遮罩、神秘骰子模式、后退规则、跳转规则、惩罚提示和按版本编辑事件文本。自定义事件按版本独立保存，可以恢复当前版本默认值。

神秘骰子模式只隐藏界面上的点数，规则引擎仍会正常使用真实骰子结果；棋子移动会按格子逐步播放，动画期间不能重复掷骰。

## 快速打开

推荐通过本地静态服务器打开，保证 ES modules 正常加载：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/index.html`。

自动化测试：

```bash
node --test tests/*.test.mjs
```

## 存档兼容

新版使用 `flight_chess_game_v2`、`flight_chess_settings_v2` 和 `flight_chess_custom_events_v2:<version>`。会自动读取旧版的 `flight_chess_progress` 与 `flight_chess_player`，并转换为统一状态。
