# 设置页 UI 与颜色选择器设计

## 目标

优化设置页的信息层级和手机操作体验，并修复玩家颜色已经生效但颜色选择框仍呈白色的问题。

## 设计

- 保留浏览器原生颜色选择器作为实际输入，确保桌面、手机和 iPad 都能打开系统取色面板。
- 每位玩家使用一个独立的颜色行，显示玩家名称、与棋子一致的圆形色块和当前 HEX 值。
- 原生颜色输入覆盖在颜色行上并透明显示；用户点击整行即可选色，外部色块和 HEX 值在输入时实时更新。
- 设置页面减少大标题占用，强化分区标题和内容间距；手机端保存操作改为整行按钮，降低误触。
- 不改变设置存储结构、游戏规则或现有玩家颜色数据。

## 验收

- 初次打开设置页时，两位玩家的颜色行显示各自已保存颜色，不显示白色占位。
- 修改颜色后，色块和 HEX 文本立即更新；保存后游戏棋子使用相同颜色。
- 设置页在 375px 手机、768px iPad 和桌面宽度下无重叠或文本溢出。
- 现有自动化测试全部通过。
